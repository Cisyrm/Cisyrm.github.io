# 保研经验个人主页（迟.）

静态网站，无原始 Word、PPT 或 PDF 下载链接。本版本未添加登录、注册和访问控制。

## 网站入口
- `index.html`：首页
- `guide.html`：11 页保研规划幻灯片（已去掉封面、结束页与活动署名）
- `experience.html`：26 项申请概览（在上）与 9 篇院校经历（在下）
- `schools/*.html`：9 篇院校经历文章，包含 12 张原始资料配图
- `questions.html`：可筛选、可搜索面试题库
- `assets/`：样式、脚本、题目数据、幻灯片图片、院校图片

## 使用
解压后将全部文件及文件夹直接上传至仓库根目录，确保 `index.html` 在根目录。不要只上传 ZIP。部署仍可使用 GitHub Pages，用户可通过仓库对应网站地址访问。

## 隐私与公开性（请在上线前处理）
* GitHub Pages 当前仍是公开访问，所有网页内容、展示图片、题库数据可以直接查看。邀请码注册与账号密码保护仍未实现。
* 旧版公开 GitHub 仓库的历史提交中曾包含原始附件和真实姓名。即使最新版本删除，原始文件仍可能通过旧提交直接访问。请不要将本 ZIP 上传至原有公开仓库后就认为历史记录已被清除。
* 如果需要防止通过 GitHub 读取历史，请使用新的不含历史记录的私有仓库，并部署到有鉴权保护的服务；旧公开仓库需要单独处理。
* 网页展示的幻灯片及图片可以被截图保存，无法实现绝对防复制。
