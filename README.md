# 迟. 的保研经验个人主页（V5.1）

本次主要更新「保研规划与准备」页面：保留原始《保研分享会》PPT 第 2—12 页的全部有效内容及顺序，改用适合网页阅读的章节、卡片、对比栏和纵向时间线展示；原 PPT 内四张局部配图继续保留。已去除第一页、最后一页、活动页眉与活动落款。

## 网站页面
- `index.html`：主页（匿名昵称「迟.」）。
- `guide.html`：11 个主题的长文章，桌面端带左侧章节导航，手机端单栏适配。
- `experience.html`：26 项申请概览及 9 篇院校经历。
- `schools/`：院校文章及原始配图。
- `questions.html`：162 道通用题，以知识主题、学校、面试类型三个入口筛选。

网站还没有邀请码、账号密码或管理员功能。GitHub Pages 发布后为公开网站。

## 更新到 GitHub Pages
1. 将本压缩包解压。
2. 上传并覆盖仓库根目录中的 `guide.html`，同时上传新文件 `assets/guide-web.css`、`assets/guide-web.js`。如要同步完整 V5，可上传整包内容。
3. 仓库若还保留旧版的 `downloads/`、`assets/slides/`、`resources.html`，需要另行删除。上传新版文件不会自动删除这些旧文件。
4. 旧的公开 Git 提交历史可能保存过原始姓名及资料，覆盖新文件不会清除历史。请在公开发布前单独处理。

本网站包不提供原始 PPT、Word、PDF 的下载入口，亦不包含原始资料文件。
